Features

New thread

A new thread opens as a blank draft with four starting points. The session starts with your first message, so a thread you abandon leaves nothing behind.

Changes and diffs

Unified or split diffs with the changed words marked, next to the chat. Comment on any line and send the comments to the agent as one message. Stage, commit, pull, push and open a pull request from the same pane.

Approvals

See the exact command, or a diff of the edit, before it runs. Allow it once or for the session, deny it, or deny it and say what to do instead. A request expires after 10 minutes.

Worktrees

A thread can work in its own git worktree, so two threads can run in one repository at once. Apply to Local brings the result back as uncommitted changes.

Command palette

Native app

Built with Tauri on your system's webview. Its built-in agent connects to your chosen provider, and the window opens while threads load behind it.

  • Find in thread

    ⌘F searches every message in the open thread, including ones scrolled out of view.

  • Prompt rail

    One dash per message you sent, at the edge of the transcript. Pick one to jump back to it.

  • Undo and reapply

    A finished turn can be undone and reapplied from saved file states, new and deleted files included.

  • Custom slash commands

    Save your own prompts in Settings. They appear in the slash menu after skills.

  • Estimated cost

    The context meter shows the thread's estimated spend next to its token counts.

  • Secure API keys

    Keys are stored in the macOS Keychain and are sent only to the provider you choose.
